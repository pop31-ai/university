# PROCEDURE.md — СБОРКА ВИДЕО-МАТЕРИАЛОВ (грамотно)

Мы уже прошли накопление: схемы по предметам, материалы с картинками в PDF,
малые статьи-подписи, полиарт. Теперь — процедура, как **грамотно собрать из
этого видео-материалы** по согласованной парадигме ролика
(что сказать ⊕ как грамотно рассказать; учитель с учениками; профессор-веха;
трёхслойные карты; библиотека).

Ролик — не отдельное «с нуля» творение, а **сборка накопленных артефактов**.
Ничего не пересобираем с нуля: «готовое не терять».

## Исходники (что уже есть — вход конвейера)

| Исходник | Где | Что даёт для ролика |
|----------|-----|---------------------|
| Схемы по предметам | `plan/lines/{math,physics,polyart}.js`, `sessions/*.json` | шаги, формулы, структуру «от а до я» |
| Материалы с картинками в PDF / малые статьи | `articles/short/*` (малые статьи-подписи), наглядные мазки доски и справочники кабинета | наглядность, подписи к кадрам. В полиарте картинка — элемент живой доски (схема/график/облако), а не вложенный файл |
| Кейсы | `cases/*` | примеры, «почему так / почему не другие», развилки |
| Конспекты-сессии | `sessions/*.json` | реальный мазковый материал, результат (outcome) |
| Полиарт | `plan/lines/polyart.js`, полиарт-сессии, `production`-слой | пространство: помещение и камеры |
| Карты роликов | `plan/videos/*.json` | раскадровку А→Я с тремя слоями и учителем |

## Выход (цель конвейера)

Играемая видео-сессия (`videos/<id>.json`) — та же структура, что и урок
(strokes с таймингами, развороты ленты, вопросы в зал), но построенная **по
карте ролика** и **грамотно рассказанная**: с зацепкой, средним/крупным планом,
задержкой взгляда, финальным якорем и точками фидбека учителю.

## Процедура (7 шагов)

### Шаг 1. Вход: выбрать сессию
Из `plan/semester.json` берём сессию (id, engine, room, teacher, outcome) и её
карту `plan/videos/<id>.json`. Определяем тип: предметный (math/physics) или
полиарт (pair=2).

### Шаг 2. Извлечь содержание (слой «что сказать»)
Из `sessions/<id>.json` (через `plan/videos.js::extractContent`) берём мазки с
текстом — шаги, формулы, определения. Это **под запись**.

### Шаг 3. Приложить наглядность (PDF-картинки / малые статьи)
К ключевым шагам привязываем наглядность: для предметных — малые статьи
(`articles/short/*`) и справочники; для кейсов/развилок — `cases/*`. Картинка
в ролике = мазок-иллюстрация (схема/график/облако) на соответствующей фазе.

### Шаг 4. Разложить по фазам А→Я (карта)
По карте раскладываем материал на фазы:
- А зацепка — провокация; Б якорь — определение; В разбор — шаги+наглядность;
- Г развилка — пример/опыт, «если так — то так»; Д сборка — итоговая схема;
- Я финал — якорь `ИТОГ · ОСВОИЛ: <outcome>`.

### Шаг 5. Рассказать (слой «как грамотно рассказать»)
По `narration` (уровню и фазам) задаём: темп, план камеры, задержку взгляда,
разворот ленты между фазами, паузу на осмысление в Б/Я. Выставляем `t`/`dur`
каждого мазка под длину ролика (карта даёт `at`-сетку).

### Шаг 6. Учитель и пространство
- Встраиваем **учительский слой**: вопрос в зал в фазе В, пауза на ответ,
  «почему так / почему не другие» в фазе Г.
- Для полиарт: model помещения и **расположение камер** (`production`) — какая
  камера ведёт фазу; для предметных — по планам камер из `production`.
- Ставим `feedback_teacher`-точку на каждой фазе (для цикла риск→фидбек).

### Шаг 7. Проверка и сдача
- Прогон: ролик строится без ошибок, длина ≈ длине сессии, outcome в финале.
- `feedback`-карта: что собрать после прогона (дошло/не дошло, упущенные).
- Поместить в библиотеку (`videos/`), внести в реестр плеера.

## Правила процедуры

1. **Ничего не пересобирать с нуля** — ролик собирается из накопленных
   артефактов (схемы, подписи, кейсы, конспекты, полиарт-кадр).
2. **Предметные** — наполняются конспектом + наглядностью; **полиарт** —
   пространством и камерами (главный слой), конспект приложен.
3. **Рассказать, а не прочитать вслух**: темп/план/пауза/разворот — обязательны
   (слой narration).
4. **Никакого экзамена ученику**: мера — сходимость выборки и её выбор
   (ASSESS.md), фидбек учителю, а не оценка учащемуся.
5. **Библиотека**: каждый собранный ролик — артефакт в `videos/`, готовое не
   теряется, любое извлечение по каталогу.

## Текущий статус реализации

Готово: карты роликов (`plan/videos/*.json`, 37 шт.) с тремя слоями
(conspect/spirit/narration), учителем и production (камеры). Следующий шаг
реализации — **сборщик «карта → играемая видео-сессия»** (Шаг 5–7): генератор,
который по карте и исходному конспекту строит `videos/<id>.json` (strokes),
имея те же движки, что плеер.
